# The Implications of Large-Scale Test-Time Compute

## 概要
Noam Brown（OpenAI）による論説。LLM の性能向上に伴い、**ベンチマーク成績が（モデルサイズや事前学習よりも）テスト時の計算量(test-time compute)に左右される度合いが増している**こと、その含意として **現代 LLM の能力上限(capability ceiling)は未知の領域でありうる**ことを論じる position essay。
