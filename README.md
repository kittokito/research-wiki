# research-wiki

社内勉強会の発表資料を作成・保管するリポジトリ。1回の発表を1フォルダにまとめ、スライドと台本を分けて置く。

論文の取り込み wiki（`sources/` `evidence/` `wiki/` `index/`）としての機能は廃止した。過去の内容はコミット `6b46c0a` 時点の履歴から参照できる。

## ディレクトリ構成

```
research-wiki/
└── presentations/
    └── 2026-09-10/           # 開催日 YYYY-MM-DD が1回分の単位
        ├── README.md         # テーマ・構成・出典と査読状況
        ├── 00-intro.md       # スライド。NN は発表順
        ├── 01-....md
        ├── scripts/          # 台本。スライドと同名
        │   ├── 00-intro.md
        │   └── 01-....md
        └── figures/          # 原典から切り出した図
```

## スライドと台本の分担

| | 置く場所 | 中身 |
|---|---|---|
| スライド | `NN-*.md` | 聞く側が見るもの。図・表・キーメッセージだけ。節を `## S1.` `## S2.` と番号で切る |
| 台本 | `scripts/NN-*.md` | 話す側が手元で見るもの。`### S1` でスライドの節番号に対応させる |

台本には、スライドに載せなかった実験設定の細部、原典内の数値の不一致、想定問答（**聞かれたら**）を入れる。

図には役割コメントを添える。本筋でない図はその旨を書く。

```markdown
![](figures/pf-fig4-scale.png)
<!-- 役割: 「小さい・未熟なモデルだから壊れる」説を潰す -->
```

`scripts/` に分けているのは 2026-09-10 以降。それ以前の回は台本を持たない。

## 資料作成の進め方

1. `presentations/{開催日}/` を作り、README にテーマと扱う論文を書く
2. 原典の図を `figures/` に切り出す。ファイル名は `{論文の略号}-fig{番号}-{内容}.png`
3. スライドを書く。数値・引用は必ず原典に当たって確認する
4. 台本を `scripts/` に書き、スライドの節番号で対応させる
5. README の枚数表を実際の節数に合わせる

数値と表現の強度は原典と照合する。Abstract と本文で主張の強さが違う場合は、本文側に合わせたうえで台本に落差を書く。
